# @vngamemini/examination

Data processing engine for web examinations.

`@vngamemini/examination` provides a predictable pipeline for normalizing,
validating, evaluating, summarizing, and scoring examination data.

The library focuses on examination data processing only.

Application-level concerns such as UI, navigation, timers, randomization,
events, persistence, and rendering remain outside the core.

## Installation

```bash
npm install @vngamemini/examination
