# @vngamemini/examination

Data processing engine for web examinations.

## Features

- Examination data model
- Subject and Question collections
- Answer and multiple-answer support
- Data normalization
- Data validation
- Examination sessions
- Session navigation
- Session timer
- Evaluation
- Score and Result
- JSON serialization and restoration
- Extensible question types
- Public API for application integration

## Installation

```bash
npm install @vngamemini/examination
```
